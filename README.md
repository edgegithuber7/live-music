# Live Music — Downloads

The download page for Live Music: https://edgegithuber7.github.io/live-music

Installers for Windows and Android are attached to each [release](https://github.com/edgegithuber7/live-music/releases).
Upload them with these exact file names so the page's buttons always get the newest version:

- `LiveMusic-Setup.exe` — Windows installer
- `LiveMusic.apk` — Android app

The Mac version installs through Glaze.
