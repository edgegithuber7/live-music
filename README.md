# Live Music — Downloads

The download page for Live Music: https://edgegithuber7.github.io/live-music

Installers are attached to each [release](https://github.com/edgegithuber7/live-music/releases).
Upload them with these exact file names so the page's buttons always get the newest version:

- `LiveMusic.dmg` — Mac, Apple silicon (M1–M6)
- `LiveMusic-Intel.dmg` — Mac, Intel
- `LiveMusic-Setup.exe` — Windows installer
- `LiveMusic.apk` — Android app

Also attach `SHA256SUMS.txt` with the SHA-256 of each file. The Mac version is also available
through Glaze.
